# ♿ Accessibility

[← Back to main list](../README.md)

### [Bionic Reading](https://chromewebstore.google.com/detail/bionic-reading)
**Category:** Accessibility · **Platforms:** Chrome  
Bolds the first part of each word to guide the eye and speed up reading.

### [High Contrast](https://chromewebstore.google.com/detail/high-contrast)
**Category:** Accessibility · **Platforms:** Chrome  
Applies high-contrast color filters to any webpage for low-vision users.

### [Read Aloud](https://readaloud.app/)
**Category:** Accessibility · **Platforms:** Chrome, Firefox, Edge  
Free text-to-speech extension that reads webpage content aloud in many languages.

### [Dark Reader](https://darkreader.org/)
**Category:** Accessibility · **Platforms:** Chrome, Firefox, Edge, Safari  
Generates dark mode for every website, with brightness/contrast controls.

### [Helperbird](https://helperbird.com/)
**Category:** Accessibility · **Platforms:** Chrome, Firefox, Edge  
All-in-one accessibility toolkit: text-to-speech, dyslexia fonts, reading rulers, and color overlays.

### [Read&Write](https://www.texthelp.com/products/read-and-write-education/)
**Category:** Accessibility · **Platforms:** Chrome  
Literacy support toolbar with text-to-speech, word prediction, and translation (free for basic use).

### [Speech to Text](https://chromewebstore.google.com/detail/speech-to-text)
**Category:** Accessibility · **Platforms:** Chrome  
Dictate text into any web form using your browser's speech recognition.

### [Visor - Color Blindness Simulator](https://chromewebstore.google.com/detail/visor-color-blindness-sim)
**Category:** Accessibility · **Platforms:** Chrome  
Simulates various forms of color blindness to test how your site reads for colorblind users.

### [High Contrast Alt: Dark Mode](https://chromewebstore.google.com/detail/dark-mode)
**Category:** Accessibility · **Platforms:** Chrome, Firefox, Edge  
Site-wide dark mode with adjustable brightness/contrast/sepia filters.

### [Spreeder](https://chromewebstore.google.com/detail/spreeder)
**Category:** Accessibility · **Platforms:** Chrome  
RSVP speed-reading tool that flashes text word-by-word to boost reading speed.
