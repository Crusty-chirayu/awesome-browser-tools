# 👨‍💻 Developer Tools

[← Back to main list](../README.md)

### [JSON Viewer](https://chromewebstore.google.com/detail/json-viewer)
**Category:** Developer Tools · **Platforms:** Chrome  
Pretty-prints raw JSON responses in the browser with collapsible trees.

### [React Developer Tools](https://react.dev/learn/react-developer-tools)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Inspect React component hierarchies, props, and state directly in DevTools.

### [Wappalyzer](https://www.wappalyzer.com/)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Identifies the tech stack (frameworks, CMS, analytics) any website is built with.

### [WhatFont](https://chromewebstore.google.com/detail/whatfont)
**Category:** Developer Tools · **Platforms:** Chrome  
Click any text on a page to instantly see the font family and size in use.

### [Window Resizer](https://chromewebstore.google.com/detail/window-resizer)
**Category:** Developer Tools · **Platforms:** Chrome  
Quickly resize the browser to test responsive breakpoints without DevTools.

### [ColorPick Eyedropper](https://chromewebstore.google.com/detail/colorpick-eyedropper)
**Category:** Developer Tools · **Platforms:** Chrome  
Grabs the exact hex value of any pixel on screen, including inside images.

### [CSS Peeper](https://csspeeper.com/)
**Category:** Developer Tools · **Platforms:** Chrome  
Design-focused CSS inspector — pulls colors, fonts, and assets without opening DevTools.

### [EditThisCookie](https://www.editthiscookie.com/)
**Category:** Developer Tools · **Platforms:** Chrome, Edge  
View, edit, add, and delete browser cookies with a clean UI.

### [JSONView](https://github.com/gildas-lormeau/JSONView-for-Chrome)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox  
Auto-formats raw JSON responses viewed in the browser into readable, collapsible trees.

### [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview)
**Category:** Developer Tools · **Platforms:** Chrome  
Google's built-in auditing tool for performance, accessibility, SEO, and best practices.

### [ModHeader](https://modheader.com/)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Modify HTTP request/response headers on the fly for testing APIs.

### [Octotree](https://www.octotree.io/)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Adds a file-tree sidebar to GitHub repos for faster code navigation.

### [Refined GitHub](https://github.com/refined-github/refined-github)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Open-source extension that adds dozens of small quality-of-life features to GitHub's UI.

### [Requestly](https://requestly.com/)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Intercept, modify, redirect, and mock API requests directly in the browser.

### [VisBug](https://visbug.web.app/)
**Category:** Developer Tools · **Platforms:** Chrome  
In-browser visual design/dev tool — edit layout, spacing, and text of any live page.

### [Web Developer](http://chrispederick.com/work/web-developer/)
**Category:** Developer Tools · **Platforms:** Chrome, Firefox, Edge  
Classic toolbar adding dozens of web dev utilities: outline elements, disable JS/CSS, view resized images, and more.

### [Postman Interceptor](https://learning.postman.com/docs/sending-requests/capturing-request-data/interceptor/)
**Category:** Developer Tools · **Platforms:** Chrome  
Captures browser network requests directly into Postman for API testing.

### [WhatFont Alt: Fontanello](https://chromewebstore.google.com/detail/fontanello)
**Category:** Developer Tools · **Platforms:** Chrome  
Right-click any text to instantly reveal font family, size, and weight.

### [Window Resizer Alt: Responsive Viewer](https://responsiveviewer.org/)
**Category:** Developer Tools · **Platforms:** Chrome  
Shows a page across multiple device viewports side-by-side simultaneously.
