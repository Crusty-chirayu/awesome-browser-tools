# 🗂️ Misc / Everything Else

[← Back to main list](../README.md)

Tools that don't fit neatly elsewhere go here — get them added, and if enough pile up in one theme we'll spin off a new category.

### [Video Speed Controller](https://chromewebstore.google.com/detail/video-speed-controller)
**Category:** Misc · **Platforms:** Chrome, Firefox  
Adds keyboard shortcuts to speed up/slow down any HTML5 video, including 2x+ on Netflix/YouTube.

### [Weava Highlighter](https://www.weavatools.com/)
**Category:** Misc · **Platforms:** Chrome  
Highlight and annotate PDFs and webpages, organized into folders for research.

### [Google Translate](https://chromewebstore.google.com/detail/google-translate)
**Category:** Misc · **Platforms:** Chrome, Firefox, Edge  
Instantly translate selected text or entire pages into 100+ languages.

### [Instant Data Scraper](https://chromewebstore.google.com/detail/instant-data-scraper)
**Category:** Misc · **Platforms:** Chrome, Edge  
Extracts tabular/list data from any webpage into a spreadsheet with no coding.

### [Print Friendly & PDF](https://www.printfriendly.com/)
**Category:** Misc · **Platforms:** Chrome, Firefox  
Strips ads/clutter from a page and exports a clean, printable PDF version.

### [TabCloud](https://chromewebstore.google.com/detail/tabcloud)
**Category:** Misc · **Platforms:** Chrome  
Save and sync entire browser sessions across computers using local/cloud storage.

### [Wayback Machine](https://web.archive.org/)
**Category:** Misc · **Platforms:** Chrome, Firefox, Edge  
Instantly check archived versions of any webpage via the Internet Archive.

### [Web Scraper](https://webscraper.io/)
**Category:** Misc · **Platforms:** Chrome  
Point-and-click web scraper for extracting structured data from multi-page sites.

### [Downloader for Instagram](https://chromewebstore.google.com/detail/downloader-for-instagram)
**Category:** Misc · **Platforms:** Chrome  
Download public Instagram photos and videos directly from your browser.

### [Speed Dial 2](https://speeddial2.com/)
**Category:** Misc · **Platforms:** Chrome, Firefox, Edge  
Customizable visual bookmarks/new-tab dashboard for your most-used sites.
