# Code of Conduct

Be respectful. Be constructive. No harassment, spam, or self-promotion disguised as "contributions" (i.e. don't submit your own barely-functional tool just to farm a backlink).

Disagreements about categorization or whether a tool qualifies as "free enough" are fine — resolve them in PR comments, keep it civil.

Maintainers reserve the right to close PRs/issues that don't follow [CONTRIBUTING.md](CONTRIBUTING.md) or violate this code.
